PORTFOLIO / PRACTICE PROJECT

Under-Five Mortality: Data Cleaning, SQL Analysis & Dashboard

Built by Ahmed Fazil to demonstrate an end-to-end data workflow: cleaning raw public health data with Python (pandas), analyzing it with SQL (SQLite), and visualizing results.

Data source: Our World in Data, sourced from the UN Inter-agency Group for Child Mortality Estimation (UN IGME) — a collaboration led by UNICEF with WHO, the World Bank, and the UN Population Division — and Gapminder. Licensed CC BY 4.0.

1. What this project is

This is a self-directed practice project, not employer work product. It uses real, publicly available child mortality data (the same UN IGME / UNICEF-family data source referenced in my CV) to demonstrate the actual mechanics of cleaning, querying, and visualizing a dataset — the specific skill gap identified when reviewing my CV for data analyst roles. Full source code, SQL queries, and data are included alongside this dashboard.

2. Data Cleaning (Python / pandas)

Raw data loaded: 400 rows, 14 entities (10 countries + 4 regional aggregates: Africa, Asia, Europe, EU-27).

  • Checked for missing values — none found in this extract.
  • Checked for duplicate (entity, year) records — none found.
  • Separated country-level rows from regional/continental aggregates (which use an OWID_ prefixed code) — aggregates must be excluded from country rankings or they distort the comparison.
  • Standardized types: year → integer, rate → float, entity names stripped of whitespace.
  • Range-check: verified all mortality rate values fall within a plausible 0–100 band.

Result: 322 clean country-level rows and 78 clean regional rows, saved as separate CSVs.

4. Dashboard

5. Key findings

  • China shows the largest relative improvement since 1990 (-89.4%), followed by Bangladesh (-79.2%) and Ethiopia (-78.0%).
  • Chad has both the highest current rate (9.73 deaths per 100 live births in 2024) and the smallest relative improvement since 1990 (-54.0%) among the countries in this dataset.
  • The European Union's regional average (0.39 in 2024) is roughly 17x lower than Africa's (6.63), though Africa has still cut its rate by more than half since 1990.
